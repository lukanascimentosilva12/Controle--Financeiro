# 💰 Controle Financeiro

Sistema web desenvolvido para controle de receitas e despesas pessoais.

A aplicação permite registrar transações, acompanhar receitas e despesas,
calcular a economia e visualizar o saldo atual de forma simples e organizada.

## 🚀 Funcionalidades

- Adicionar novas transações
- Registrar descrição e valor
- Classificar transações como receita ou despesa
- Visualizar total de receitas
- Visualizar total de despesas
- Calcular economia
- Exibir saldo atual
- Excluir transações
- Salvar transações no navegador utilizando LocalStorage
